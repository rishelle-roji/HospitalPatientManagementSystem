How it works

Two queues, two jobs.

Queue (FIFO)

Regular patients join at the rear and are called from the front, so the one who arrived first is seen first. In Java this is a Queue using add() and poll().

PriorityQueue

Emergency patients are ordered by a custom comparator, so a Critical patient is always called before a Serious or Moderate one, whenever they arrived.

The comparator rule

  1. Smaller priority number is more urgent: Critical = 1, Serious = 2, Moderate = 3.
  2. If severity is equal, the patient with the earlier arrival number goes first.

Example: add Moderate, Critical, Serious. Heap order may be Critical, Moderate, Serious, but the calling order is always Critical, Serious, Moderate.
